# 📝 推文生图插件 (anr_plugin_stories_to_images)

[Auto-NovelAI-Refactor](https://github.com/zhulinyv/Auto-NovelAI-Refactor) 的推文生图插件, 从 Excel 模板批量读取 TAG, 逐条生成推文配图并自动插入表格, 支持 vibe / 角色参考 / wildcards 等功能。

## ✨ 功能特性

- 📊 **Excel 模板驱动**: 复制随插件提供的 模板文件.xlsx, 填写 TAG 列即可批量生成
- 🖼️ **自动插表**: 生成后的图片自动按 TAG 分组插入 Excel 对应列, 排版整齐
- 🎚️ **可调数量**: 每个 TAG 可生成 1 ~ 999 张图片
- ✨ **全功能支持**: 支持 vibe, 角色参考, 角色分区, wildcards 等生成功能
- 🛡️ **中断保护**: 生成过程中停止/出错时, 已生成的图片不丢失, 每列处理完立即保存

## 📦 依赖

- openpyxl

## 🚀 使用方法

1. 在 [Auto-NovelAI-Refactor](https://github.com/zhulinyv/Auto-NovelAI-Refactor) 的插件商店中安装本插件
2. 打开「推文生图」面板
3. 点击 **📂 打开插件目录**, 找到 `模板文件.xlsx` 并复制一份
4. 打开模板文件, 填写 **TAG** 列即可 (描述列可不填), 完成后保存并关闭文件
5. 在左侧参数设置区域配置本次生成的参数
6. 点击 **📝 推文生图** 开始批量生成

> 💡 建议: 首次使用请先在主页完成一次普通文生图, 使插件能读取到上次的生成参数。

## ⚠️ 注意事项

- **停止生成后无法从某个位置继续生成**
- 选择同一个 `*.xlsx` 文件重复生成时, 图片会重叠
- 生成过程中请勿执行其它使用官网 API 的生成操作
